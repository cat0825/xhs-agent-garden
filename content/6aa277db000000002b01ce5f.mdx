## 面试者自述

这是我投简历后约到的第一家做 AI Agent 的公司，团队氛围挺好，还报销了打车费。但面试难度比我想象的大，好几次都快接不上话了，**简历上写的东西全被挖了一遍**。

## 原题 12 道

1. 自我介绍
2. 挑一个你简历上最熟悉的 Agent 项目讲讲，你主要负责哪块？
3. 你觉得 AI Agent 和普通的 LLM 对话机器人，核心区别在哪？
4. 简单说一下 Function Calling 的执行流程是怎样的？
5. 什么是 ReAct 模式？它在 Agent 里起什么作用？
6. 谈谈你对 ReAct 框架 / Function Calling 的理解，有没有落地实践过？
7. 用过 LangChain 或 LlamaIndex 吗？说说你觉得它们的优缺点。
8. 你们的 Agent 是怎么做效果评测的？有量化的指标吗？
9. 如果让你优化 Agent 的响应速度和 Token 消耗，你会怎么入手？
10. 如果产品认为 Agent 返回的结果不算 bug，你认为是缺陷，你会怎么沟通处理？
11. 你了解我们公司目前的 AI 产品吗？有什么建议？
12. 你的期望薪资是多少？

## 观察

第 10 题是很少见但很实际的软技能题：技术判断与产品判断冲突时怎么推进。第 8 题说明**评测已经是标准问项**，答不出量化指标会直接失分。
