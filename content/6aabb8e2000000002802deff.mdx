## 最有价值的信号：追问链

面试官不满足于"用没用过 LangChain"，而是沿这条链一路往下追：

```
Agent Loop 怎么跑
  → Runtime 提供什么能力
    → Harness 解决什么问题
      → Memory 怎么设计
        → MCP / Skill 怎么接入
          → Sandbox 怎么提供执行环境
```

## 面试者总结

整体偏 Agent Infra + 后端基础，"不是简单问用没用过 LangChain"。Agent 相关的问题问得比较系统，后面又集中考察了 MySQL，最后一道手撕 LRU。
