2026-09-10 到 09-23，小红书 40 条候选里有 19 条是招聘帖。其中一条 2026-09-23 发布，标题里直接写着「AI Agent Harness 方向」，发布方是腾讯混元基础模型团队。

它列的要求值得抄下来：编程基础扎实，熟悉 TypeScript / JavaScript、Python 中至少一门；**持续使用 Claude Code、Codex、Cursor 等 AI 编程工具**；了解 LLM API、Agent Loop、Tool Use。工作内容一栏写的是参与 Agent Runtime、工具调用、隔离执行环境及评测调试系统建设。

这条 JD 里**没有出现任何框架名**——没有 LangChain，没有 LangGraph，没有 CrewAI。它要的两样东西，一个是使用经验（AI 编程工具），一个是机制理解（Agent Loop、Tool Use）。

三个问题因此变得具体：

1. 9 月在招的 Agent 岗，方向和职责分别是什么？
2. JD 里的要求，和面经里被追问的能力对得上吗？
3. 哪些信号是「正在发生」，哪些只是「已经发生」？

有几件事我做不到，先说清楚：19 条里我逐条读了 **16 条**的正文，剩下 3 条本身就是已归档的面经帖（京东 AI Agent 开发岗、Agent 开发岗全是先进去再说的、已入职者复盘），内容另有专篇；这些帖子都是发布者自述，未经企业官方确认；岗位会关闭、联系方式会过期，所以我不转述邮箱、内推码这类会失效的信息。全文我会标明哪部分是正文直读、哪部分是我的归纳。

把 JD 里的要求和面经里被追问的能力摆在一起，能看到几处直接对应：

| 搭建评测流水线、环境隔离、多次 Trial、Trace 采集 | 评测工程师 JD | 字节 Infra「你们的 Agent 怎么做效果评测」 |
| Bad Case 分析与归因 | 评测工程师 JD | 面试官复盘第三层「Agent 丢失最早的关键信息，排查路径是什么」 |
| 记忆与失败恢复 | 高德 | 美团第 6 题「多轮任务如何保证记忆一致性」 |
| 长文档总结、信息压缩、上下文瓶颈 | 千问 | 虾皮第 4-5 题「上下文窗口管理」 |

对得最齐的是**评测**和**Sandbox**：JD 里写成岗位职责的东西，面经里正好是被追问到第三轮的那一类。

## 三个正在发生的信号

**一、AI 编程工具的使用经验进了 JD 明文要求。**

腾讯混元那条写的是「**持续使用** Claude Code、Codex、Cursor 等 AI 编程工具」，AI 产品岗把「有 AI Coding 经验（Workbuddy / Cursor / Claude Code 等 Agent 工具独立完成过小产品落地）」列进加分项。

这条信号和面经侧是同步的：同一批样本里，「ai agent 面经」那篇的标题直接写着「重心在 AI Coding 实践」，问的是 Claude Code 的使用习惯、AI 审核如何放行代码、被 AI 带偏怎么办。**JD 要经验，面经问细节，两边指向同一件事。**

**二、Sandbox / 隔离执行环境从概念变成了岗位职责。**

腾讯混元写「隔离执行环境」，BENYOND AI 的 Agent 基建方向写「Agent 沙箱和 LLM 网关」，高德写「在仿真和真实机器人上验证」。这不是「了解沙箱是什么」的要求，是要动手搭。

**三、评测独立成岗。**

那份拆了 10 个 JD 的帖子给出了完整职责：评测体系建设（Benchmark、分层评测集、Golden Dataset、Rubric）、Agent 全链路评测（模块分层 + 关键链路 + 端到端，覆盖任务规划 / RAG / 工具调用 / Context / Memory / 多 Agent 协作）、评测工程化（环境隔离、批量执行、多次 Trial、Trace 采集、自动评分、版本对比）、Bad Case 归因、回归评测与发布门禁、评测驱动优化。

它给了一句定义：**这个岗位本质是「定义 Agent 好不好」的人，不是传统功能测试**。

**代价在这里**：这三条信号都是「正在发生」，不是「已经发生」。7 条帖子里有 5 条明确写了面向 2028 届及以后（腾讯混元、千问），说明这批岗位主要面向低年级在读。但上海 AILab 那条的正文里写了两句不同的话：「不卡论文和 bg」，以及「我们也有充足的正职 HC」——高年级的入口在那里，不在实习岗。

## 另一条赛道：后训练与多模态

前面 16 条里，有三条不属于「应用工程」而是**训练侧**，要求和技术栈完全不同：

| 岗位 | 内容 | 关键要求 |
|------|------|---------|
| 上海 AILab · 智能体基础模型 | 智能体模型真实场景的生产能力与科学能力训练（代码生成、任务规划、长时程优化）；后训练方法研究与实现（SFT、强化学习、**Recursive Self-Improvement**）；面向 Agent 的训练数据与评测体系（高质量轨迹数据、错误修复数据、任务规划数据、多轮交互数据）；**Auto-Research** 能力提升 | 硕士及以上；Python + PyTorch / Transformers；熟悉 SFT / RLHF / DPO / PPO / **GRPO**；能独立完成实验设计、训练调参、结果分析 |
| 腾讯元宝 VLM Agent | 端到端 Agentic VLM（多模态理解 × 自主规划 × 工具调用 × 记忆）、后训练全链路（SFT / DPO、BoN + Reject Sampling 数据生产）、视觉推理增强（细粒度感知、复杂 UI 理解、Think with Images） | 在读硕士/博士，CS/AI/ML/CV/NLP；Python 熟练、数据结构算法扎实；有 LLM / VLM / 多模态训练或推理经验最好 |
| 小米（Agent 后训练） | Agent 后训练全流程（SFT、DPO、ORPO、KTO、RLHF、RLAIF、RLVR）；Agentic SFT 数据工程（真实轨迹、Self-play、拒绝采样、数据配方）；Reward Model / Preference Model / PRM；RL for Agent（长程信用分配、稀疏奖励、离线—在线 RL）；Tool-use、多轮规划、长程推理、错误恢复与记忆能力训练 | 28 届及以后；熟悉 Python、PyTorch、Transformer 与 LLM 训练原理；了解强化学习及 LLM 对齐算法 |

上海 AILab 那条还列了明确的**优先条件**，等于给出了这一行的工具清单：训练侧 LLaMA-Factory、verl、ms-swift、Megatron-LM；推理侧 vLLM、sglang；评测侧 **SWE-Bench、ALE、Auto-Research** 相关经验。

这三条把 [[03-学习内容与优先级-2026-09]] 里放在 P2 的「训练侧概念」变成了实际在招的岗位——**SFT / RLHF / PRM / 长程信用分配 / GRPO** 这些词出现在 JD 正文里，不是面经里的顺带一问。

**代价在这里**：训练侧的门槛明显更高。三条都要求「硕士及以上」或「硕博优先」，且明确写了「数学基础扎实」「了解强化学习及 LLM 对齐算法」「能独立完成实验设计、训练调参」。应用工程岗里常见的「不卡论文和 bg」在这里不成立。

## 反面的观察：JD 通胀

14 条里有两条对招聘帖本身提出了质疑，值得单独记：

**「感觉现在很多 AI 应用开发的 JD 都是瞎写的」**（♥13，正文直读）：「每天早上常规打开 boss 打野，总能刷到那种职位名称是 AI 应用开发 / Agent 开发的种种，进去一看要么是『(用)AI(Coding)开发(前后端)』。要么是 12345，一条条从 agent 开发、llm 模型部署微调、vllm 推理优化全给你写上了，结果一看工资只有 12-15。」

**「Agent 开发岗全都是混进去再说的」**（♥10，正文直读）：这个行业最特别的地方是**根本没有统一的招人标准**——不同公司挂出的 Agent 岗，实际干的活完全不一样：有的只需要调 API、写提示词，有的要搭多智能体协作系统，还有的说穿了就是招自动化开发。「招聘 JD 上写的『精通 Agent 架构』『熟练多智能体开发』，大半都是往夸张了写。很多公司自己内部都在摸索试错。」

把这两条和腾讯混元那条放在一起看，同一个市场的两种面貌：**头部团队在招 Harness / Runtime / 评测这种明确的能力，长尾岗位在把「会用 AI 写代码」包装成「Agent 开发」**。区分方法不是看职位名称，是看 JD 里有没有出现具体的系统组件（Runtime、沙箱、评测流水线、Benchmark）。

| 门槛项 | 出现的要求 |

| 毕业届次 | 2028 届及以后（腾讯混元、千问、后训练岗）；硕士及以上（AILab 智能体基础模型）；硕博在读、优秀本科生也欢迎（高德、后训练岗）；博士或优秀硕士（Benchmark 岗） |
| 到岗天数 | 每周 5 天（腾讯混元）；每周 4 天及以上（AI 产品岗、元宝 VLM）；每周 4–5 天（后训练岗）；要求线下（AILab 智能体基础模型） |
| 实习时长 | 持续 ≥ 6 个月（腾讯混元、后训练岗）；6 个月及以上优先（AILab 智能体基础模型）；3 个月以上（AI 产品岗、元宝 VLM）；半年起（千问） |
| 学历专业 | 计算机 / 软件工程 / AI 相关优先；上海 AILab 一条明确「不卡论文和 bg」，另一条要求「硕士及以上」；训练侧三条均要求硕博 |
| 地点 | 北京 / 深圳（腾讯）、杭州（千问）、北京海淀（BENYOND AI）、上海（AILab）、北京（后训练岗） |
