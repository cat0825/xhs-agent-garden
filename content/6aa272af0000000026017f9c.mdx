## 面试信息

- **面试公司**：京东
- **面试岗位**：AI Agent
- **面试时间**：1h30min

## 一面

1. 自我介绍，介绍你的 Agent 项目，你负责哪些模块？
2. 讲 Agent 完整执行流程，解释 ReAct 的 Thought / Action / Observation。
3. LangGraph 和 LangChain 的区别？Workflow 和 Agent 如何选型？
4. Agent 死循环：单机怎么做熔断？分布式为什么不能用内存计数？Redis 方案怎么实现？
5. 工具调用失败有哪几类？模型输出非法 JSON 怎么处理？怎么区分是 Prompt 问题还是模型能力不足？
6. 简述 RAG 完整链路；向量库和 MySQL 在电商业务里各自的作用？
7. 库存、价格这类实时业务数据能不能放进向量知识库？为什么？
8. 什么是 Lost-in-the-Middle，有哪些解决办法？
9. Redis 缓存穿透、击穿、雪崩分别是什么，解决方案？
10. MySQL 索引底层是什么？有哪些索引失效场景？
11. RocketMQ 消息积压，排查思路是什么？
12. 是否能接受使用 Java 栈（Spring AI）开发 Agent？
13. 算法反转链表（手撕代码）

## 二面

1. 设计京东导购 Agent，支持自然语言选购、比价、查库存售后、多轮工具调用、高并发。讲架构和难点。
2. 用户需求模糊（不知道预算、用途），导购 Agent 该怎么处理？
3. 电商场景 Agent 幻觉有什么危害？工程上如何规避幻觉、防止资损？
4. 如何搭建 Agent / RAG 评测闭环？知识库频繁更新，怎么避免旧脏数据召回？
5. 什么场景适合拆多 Agent？多 Agent 怎么通信？子 Agent 超时失败如何容错？
6. 京东导购业务中，Workflow 和 Agent 如何混合落地？
7. 大量用户反馈 Agent 推荐的商品无货，你的排查与迭代思路？

## 三面

1. 电商导购 Agent 和通用问答 Agent 最大区别是什么？
2. 你的 Demo 直接上线京东，最大缺陷是什么？重构优先改哪里？
3. Agent 落地最大瓶颈是什么？放到零售场景怎么解决？
4. 为什么投递京东 Agent 岗位，而不是其他公司大模型岗位？
5. 如果任务完成率长期上不去，你会怎么做？会不会放弃 Agent 改用 Workflow？

## 点评

**业务场景极具体**（电商导购、库存价格、资损），是本次采集中"最不像八股"的一份。两个高频追问值得单独准备：

- **实时数据能不能进向量库**（Q7）——答案是"不能直接放"，库存/价格属于强实时、强一致数据，要走 MySQL/缓存 + 工具调用，向量库只放半结构化知识。
- **幻觉的资损风险**（二面 Q3）——电商场景幻觉直接等于赔钱，所以要"工具查证 + 阈值过滤 + 不承诺不确定信息"。
