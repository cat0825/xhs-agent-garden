## 一面原题 23 道

### 项目与 Prompt

1. 自我介绍
2. 这个项目是自己独立完成的，还是参考了开源项目？
3. 项目中最有挑战的部分是什么？个人负责什么，最终产出如何？
4. 项目中出现模型幻觉时，如何处理？
5. Prompt 是如何设计和优化的？
6. 除了基础约束外，还使用过哪些 Prompt 优化方法？

### Agent 设计

7. Agent 的短期记忆和长期记忆如何实现？
8. 如果从零设计一个 Agent，需要考虑哪些核心模块？
9. 工具或 API 调用超时、报错时，系统如何处理？
10. 是否考虑过让大模型参与异常处理或自动恢复？
11. Token 消耗过快时，如何排查和优化？
12. 是否写过 Skill？通常如何设计和评估一个 Skill？

### AI Coding 与上下文

13. 常用哪些 AI Coding 工具？使用 Claude Code 时有哪些习惯？
14. 上下文为什么需要压缩？压缩后丢失细节如何处理？
15. 如何理解 Spec Coding 和 Harness？
16. Harness 为什么可能提升 Agent 的任务完成能力？

### Java 后端

17. Java 线程池有哪些核心参数和执行流程？
18. 如果让你重新设计一个线程池，会考虑哪些方面？
19. class 文件如何被加载到 JVM 中？
20. MySQL 的 undo log、redo log 和 binlog 有什么区别？
21. 什么是两阶段提交？

### 算法与反问

22. 算法题：合并两个有序数组
23. 反问

## 这场面试的两个信号

**Harness 第一次以正式考题出现**，而且问的不是名词解释，是"为什么能提升任务完成能力"这种原理级问题。

**候选人的 AI Coding 实践本身已进入考察范围**：Skill 怎么设计、Claude Code 有什么使用习惯，都成了面试题。
