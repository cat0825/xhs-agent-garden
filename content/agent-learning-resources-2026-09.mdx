## 资源一：Agent 工程师学习路线仓库

一份以「16 周从基础到 Offer」为主线的仓库，README 本身就是一张路线图，按周交付 RAG、Agent、MCP 与生产化作品集。

它把内容分成三大块：

| 板块 | 覆盖内容 |
|------|---------|
| **通用知识 / 核心技术** | 12 周进阶路线、Agent 核心概念与设计模式（ReAct / Plan-and-Execute / Multi-Agent）、框架全景（LangChain / AutoGen / CrewAI 横评）、LangChain 与 LangGraph 深度解析、RAG 核心知识与面试题、Agentic RAG 与 GraphRAG、**Context Engineering 上下文工程**（含 Anthropic 最新实践）、Agent 安全与评估体系 |
| **面试题库** | 最新面经索引（牛客 / 小红书 / 知乎 / CSDN / GitHub）、核心概念详解与参考答案、八股文完整答案集（69 题）、DataWhale 开源题库、牛客高赞拷打题合集、技术知识点速查 |
| **进阶面试题** | Agent 核心概念进阶篇、系统设计进阶篇、AI 协作与工程化进阶篇、交互式算法题图谱（附可折叠 Java 解法） |

它还给了一张**公司覆盖矩阵**，按「岗位要求 / 面试题 / 真实面经」三列标注完成度：

- **国内**：阿里、字节、小红书、百度、腾讯、美团、蚂蚁、华为、快手
- **海外**：OpenAI、Anthropic、Google DeepMind、Microsoft，以及初创公司综合攻略

## 资源二：Agent Interview 100

一个 **100 题 / 11 模块 / 四阶递进**的 Agent 题库，MIT 许可、中文。每个问题都按「简短回答 → 详细解析 → 误区 / 面试追问 → 参考资料」四层展开。

它的知识地图结构是：

```
入门基础 → 核心能力 → 工程实践 → 生产生态
```

| # | 模块 | 题量 | 覆盖 |
|---|------|------|------|
| 01 | Agent 架构 | 12 | Loop / 架构模式 / **Harness** |
| 02 | RAG | 9 | 检索增强全链路 |
| 03 | 工具调用 | 10 | Function Calling / MCP / 安全 |
| 04 | 多智能体 | 10 | 编排 / 通信 / **A2A** |
| 05 | 记忆与状态 | 7 | 分层记忆 / 上下文 |
| 06 | 规划与推理 | 9 | CoT / MCTS / Agentic RL |
| 07 | 提示工程 | 10 | 结构化输出 / 上下文工程 |
| 08 | 评估 | 9 | 基准 / **LLM-as-a-Judge** / 回归 |
| 09 | 安全与对齐 | 9 | 护栏 / 沙箱 / 红队 / 合规 |
| 10 | 生产与部署 | 13 | LLMOps / 灰度 / 扩容 / 灾备 |
| 11 | 框架 | 6 | LangGraph / 选型 / 自研 |

难度配比：**基础 ≈30% / 中级 ≈50% / 高级 ≈20%**。

## 交叉验证：两边的排序几乎一致

这是本次调研里最有意思的发现——我们是从**真实面经反推**得出优先级，它是从**题库设计**推导，两条独立路径撞到了同一个结论：

| 主题 | 本站优先级 | Agent Interview 100 | 结论 |
|------|-----------|---------------------|------|
| Agent 架构 / Loop / Harness | **P0 + P1** | 模块 01（12 题，题量最多之一） | ✅ 一致 |
| 工具调用与异常处理 | **P0** | 模块 03（含安全） | ✅ 一致 |
| 上下文与记忆 | **P0** | 模块 05 + 07 | ✅ 一致 |
| RAG（含 Agentic RAG） | **P0** | 模块 02 | ✅ 一致 |
| 多智能体 / A2A | **P1** | 模块 04 | ✅ 一致 |
| 评估（LLM-as-a-Judge） | **P1** | 模块 08 | ✅ 一致 |
| **安全与对齐** | **P1** | 模块 09（9 题） | ✅ 一致（都是独立新增） |
| 生产与部署 / 成本 | **P2** | 模块 10（**13 题，题量最多**） | ⚠️ 它的权重比我们更高 |
| 框架 | **P2**（二选一吃透即可） | 模块 11（6 题，题量最少） | ✅ 一致 |

**唯一值得修正的一点**：`生产与部署` 在它的题库里是**题量最多的模块（13 题）**，而我们此前把它放在 P2。结合京东/美团面经里的高并发、分布式锁、缓存一致性、消息队列积压，这个方向确实被我低估了——如果目标是大厂生产环境岗位，应该从 P2 提到 P1。

## 怎么用这两份资源

1. **当索引，别当教材**——它们的价值是"告诉你该学什么"，具体深度仍要靠项目实践
2. **用 Agent Interview 100 自查**——100 题按模块过一遍，答不上来的模块就是你的短板
3. **用公司覆盖矩阵定投递目标**——按"岗位要求 / 面试题 / 真实面经"三列挑覆盖完整的公司
4. **和本站面经文档交叉读**——题库给框架，面经给真实问法，两者互补
