## 原题 14 道

覆盖面最完整的一份：Agent 理论、RAG 进阶、后端基础、算法各占约四分之一，几乎可以直接当复习大纲。

### Agent 基础与编排

1. 单 Agent、多 Agent 和 Workflow 编排模式各有什么优势？
2. ReAct Agent 的核心执行流程是什么？Thought、Action、Observation 分别承担什么作用？
3. Agent 调用工具后，工具返回结果时消息结构如何设计？为什么需要单独设计 Tool Message？
4. Agent 中的短期记忆和长期记忆分别如何实现？哪些信息适合长期保存？
5. 当对话超过模型上下文窗口限制时，通常有哪些处理方案？滑动窗口和动态摘要各有什么优缺点？

### RAG 进阶

6. RAG 系统为什么需要设计父子索引？检索较小文本块、返回完整父文档解决了什么问题？
7. BM25 关键词检索和向量检索通常如何结合使用？Rerank 模型应该放在哪个阶段？
8. 知识库持续更新时，如何处理向量索引更新、缓存失效以及旧文档仍被召回的问题？

### 多模态与训练侧

9. 多模态 Agent 中，视觉编码器提取的信息如何与语言模型融合？
10. Agent 训练中的 SFT、强化学习和 Agentic CFT 分别解决什么问题？为什么需要 Mask Observation Token？

### 后端基础

11. Redis 在 Agent 系统中可以承担哪些作用？不同场景应该如何设计过期策略？
12. 消息队列在 Agent 系统中主要解决什么问题？为什么不直接使用数据库传递任务状态？
13. MySQL 联合索引在什么情况下无法有效使用？LIKE 查询在什么条件下可以使用索引？

### 算法

14. 如何反转单链表？时间复杂度和空间复杂度是多少？
