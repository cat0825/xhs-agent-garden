### 图 p02：主包个人背景

高学历低能力，大三大四研一一直在玩和摆烂，0 实习 0 科研 0 项目：
1. 快要忘干净的 C++ 和分不清元组列表字典的 Python
2. 快要忘干净的数据结构和算法（大二学的）
3. 快要忘干净的操作系统和计网
4. 本科毕业论文用 coze 搭的跑不通的教学 agent（基本只有前端能看）
5. 后端基础为零：redis、mq 没听过，mysql 大二大作业改过学长的图书馆管理系统
6. 机器学习/深度学习基础为零（复习考研时还问同学 SGD 是不是新加坡元，同学说那是随机梯度下降）
7. LLM：开始学习前分不清 tensorflow 和 transformer

**最终效果**：没申到互联网大厂，去向是一家教育大厂科技部的转正实习，薪资是正常互联网开发水平。

### 图 p03 / p04：三个学习阶段

**第一阶段 · 开始进入状态（3.4–4.1）**
- 3.4 确定求职方向 Agent 开发；3.14 才真正开始学
- 3.14–3.22 看完黑马 rag 视频（15h）+ 做了 20 多道 hot100（用 notion 记录每题语法和思考，力扣越刷越快）
- 3.22–4.1 不知天高地厚投递一周大败而归：面了 1 腾讯 2 阿里，连 MCP 是什么都不知道
- 心得：开始了就是胜利；黑马视频很浅但零基础能看懂，用来快速进入学习状态

**第二阶段 · 高强度学习（4.1–4.12）**
- 上午黑马深度学习、下午 hello-agent；学完又把 all-in-rag 看完
- 黑马深度学习：节奏太慢，建议下载课程文档过一遍，看不懂问 GPT，再 2 倍速快进过课。重点花功夫理解了 RNN 的词嵌入层 vs 现在的 embedding 模型、语义空间、动态/静态词嵌入的区别
- hello-agent：跳着看，跑通代码后按需精读（博主项目主要做记忆功能，就把记忆模块和源代码好好看了）
- 心得：概念不理解就看源代码——MCP 一开始各种不理解，让 GPT 写了个 MCP 客户端+服务端以及不用 MCP 的工具调用代码，瞬间就懂了
- 之后开始构思项目：小红书和 B 站搜选题，确定做一个医疗 RAG + 把 hello-agent 的智旅助手改成 LangGraph 写

**第三阶段 · 边面试边学习边调整（图 p05）**
- 面了字节和美团，终于能在项目上跟面试官有推拉，但还是挂了，开始向身边大佬取经
- 面试三要点：① 给项目包装一个真实业务场景（"医疗项目是给我朋友用的真实项目"，别说"为了学习"）② 讲清楚自己做了什么，按 STAR 法则，千万不要说得很乱 ③ 多练表达，写逐字稿/录音/找同学模拟面试
- 简历要把得分点直接呈现给面试官，不要让面试官自己找
- 期间把医疗项目大改特改，3 天每天改到深夜（活都是 cursor 干的）

### 图 p06：总结的学习路线

**基础**：Python 基础语法（列表推导式、标准库函数——不然项目代码都看不懂）；深度学习基础（理解思想：输入输出层、神经元、梯度下降、反向传播、权重更新）；Agent 基本概念（记忆、工具、知识库）

**进阶**：Python 进阶（面向对象、函数装饰器、异步编程、FastAPI）；Harness 思想（Agent 系统、上下文压缩策略、记忆系统）；RAG 相关（分词策略、索引优化、检索策略与原理、查询重构、重排策略，以及 qdrant、milvus、neo4j 等数据库对比）；Transformer（自注意力机制原理，看源代码方便理解）

ps：多看前沿资讯（如腾讯云开发者公众号），一定要掌握看官方文档的能力；每个人学习方法不一样，多思考多挑战，总结最适合自己的。
