## 最有信息量的四场

### 寒武纪 · AI Agent 开发（43 题，三轮）

本次采集中**单场题目最多、深度最接近 Agent Infra 岗**的一份。两条线索贯穿全场：

- **国产算力适配**是它区别于互联网大厂的考察重心：LangGraph 状态数据存在哪最优、MLU 芯片与 CUDA 栈的推理差异、MagicMind 动态 shape 对上层编排的反向压力、算力只有 A100 的 60% 时如何裁剪架构。
- **三面全部是工程负责人视角**：成本/延迟/失败率的核算、线上步数爆炸时优先调哪三个开关、多 Agent 错误答案的责任追溯、图定义热更新不重启。

还问到几个少见的硬题：`A2A 和 MCP 的核心区别`、`SSRF 与命令注入在 Agent 中如何暴露`、`LLM-as-a-Judge 的位置偏见/长度偏见如何消除`。

### 京东 · AI Agent 开发岗（25 题，三轮）

**业务场景最具体**的一份，围绕电商导购展开（库存、价格、比价、售后、资损）。

- 一面是标准后端 + Agent 混合考察：死循环熔断（单机 vs 分布式，为什么不能用内存计数）、非法 JSON 处理、RAG 链路、`Lost-in-the-Middle`、Redis 三兄弟、MySQL 索引失效、RocketMQ 积压。
- 二面全是场景设计：导购 Agent 架构、需求模糊怎么处理、**幻觉的资损风险**、评测闭环与脏数据召回、多 Agent 拆分时机。
- 三面是压力题："你的 Demo 直接上线京东，最大缺陷是什么？"

### 美团 · AI Agent 开发（10 题，自带参考答案）

这份的独特价值是**给出了可直接复用的答题框架**：

- **Function Calling 三层兜底**：Prompt 强约束 JSON → 代码层正则校验与字段补全 → 解析失败降级到预设固定流程
- **记忆一致性三原则**：统一写入与更新规则 / 关键业务数据做固定锚点 / 推理前优先加载核心记忆
- **向量索引选型**：高频大库用 HNSW，频繁更新用 FLAT
- **缓存与库一致性**：先更新数据库再删缓存 + 定时巡检自动修复

### 字节 · Agent 研发工程师（基础设施）

面试官不满足于"用没用过 LangChain"，而是沿这条链一路往下追：

```
Agent Loop 怎么跑
  → Runtime 提供什么能力
    → Harness 解决什么问题
      → Memory 怎么设计
        → MCP / Skill 怎么接入
          → Sandbox 怎么提供执行环境
```

流程：自我介绍 → 项目经历 → Agent Infra / Runtime → 后端基础 → MySQL → 手撕算法 → 反问。手撕是 **LRU**。

**结论**：MySQL 和算法不能放掉，这轮后半段基本是标准后端考察。

## 面试官视角：为什么大多数人撑不过三轮追问

来源：一位面试官复盘"一上午面试了六个 Agent 开发岗"（♥760）。

**核心观察**：简历清一色写得很满（LangGraph、CrewAI、MCP、RAG、记忆系统关键词全覆盖），但**问到落地细节，大部分撑不过三轮追问**。

追问是怎么展开的：

1. 从**工具调用稳定性**切入：模型调工具报错、参数不符合 schema、下游服务超时，代码层面怎么做异常处理？
   → 多数人停留在"try-except 捕获一下"
2. 继续追问：模型是直接调 API，还是先走记忆检索？工具返回结果做不做格式校验？
   → 到这一步，回答开始**缺乏逻辑链条**
3. 简历写"精通记忆系统"的：用户对话到第二十轮，Agent 丢失了最早的关键信息，**排查路径是什么**？
   → 答不出记忆分层、上下文压缩、关键信息优先召回，说明只是在调接口层面打转

**他给出的准备方法**——把项目按四个维度重新拆一遍：

| 维度 | 要能答出的问题 |
|------|--------------|
| **数据层** | 知识库怎么清洗、按什么策略切分？ |
| **工具层** | 失败重试策略是什么，超时怎么降级？ |
| **记忆层** | 多轮上下文怎么管理，关键信息怎么召回？ |
| **工程层** | Token 成本怎么控制，异常怎么收敛？ |

**一套完整的方案至少应覆盖**：日志重放机制、关键节点断言、Bad Case 闭环复盘。

## 求职体感（来自 9 月一线候选人）

**"Agent 不是一个岗位，是一类岗位"**（已入职者复盘，♥29）

- 各家要的东西天差地别：偏模型应用的、偏工程落地的、偏中台架构的。没搞清楚方向，准备的东西大概率跑偏
- **2026 年的 Agent 面试根本不关心你 API 调得多顺，全程拷问工程化能力**——"大厂要的不是会写 Agent 的人，是能控住 Agent 不失控的人"
- 拿 RAG demo 去面，被问"召回不准怎么监控、怎么评测"直接卡住
- 投递渠道别只盯大厂官网：**国聘网、中智招聘**上有不少国企和子公司的 Agent 岗，竞争小很多

**"别被 JD 吓住，先上桌再说"**（♥23）

- 这行最大的特点是**没有统一标准**，JD 上"精通 Agent 架构"大半是 HR 抄的
- 新手搞定三样算入门：**工具调用、智能循环、MCP 协议**
- 想卷赢，重点搞三个：**沙箱隔离、记忆管理、Token 成本优化**
- 求职别只搜"Agent"，顺手搜"**智能体**""**LLM 应用**"

**"不用学那么多，多投多面才是最快的"**（♥682）

> "大概学了一个月，从 6 月中到 7 月中，找实习感觉还是看运气的，多投多面才是最快的。"

## 长图面经怎么转录的（方法记录）

小红书不少高价值笔记正文全在长图里，`xiaohongshu download` 对 `search_result/` 链接会返回 `Navigation rejected`，`xhs-media` 抓到的是"页面已失效"。可用的链路是：

1. 用 opencli 浏览器会话打开笔记页（走已登录的 Chrome profile）
2. `eval` 读取 `window.__INITIAL_STATE__.note.noteDetailMap` 里的 `imageList`，拿到全部原图签名 URL
3. 图片 CDN **必须带渲染后缀** `!nd_dft_wlteh_webp_3`，否则 403；下载时带 `Referer: https://www.xiaohongshu.com/`
4. 转成 webp 后随笔记一起归档
