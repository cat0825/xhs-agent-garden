## 最有信息量的三场

### 字节 · Agent 研发工程师（基础设施）

面试官不满足于"用没用过 LangChain"，而是沿这条链一路往下追：

```
Agent Loop 怎么跑
  → Runtime 提供什么能力
    → Harness 解决什么问题
      → Memory 怎么设计
        → MCP / Skill 怎么接入
          → Sandbox 怎么提供执行环境
```

流程：自我介绍 → 项目经历 → Agent Infra / Runtime → 后端基础 → MySQL → 手撕算法 → 反问。手撕是 **LRU**。

**结论**：MySQL 和算法不能放掉，这轮后半段基本是标准后端考察。

### 虾皮 · Agent 开发一面

覆盖面最完整的一份，14 题里 Agent 理论、RAG 进阶、后端基础、算法各占约四分之一：

- 单 Agent、多 Agent 和 Workflow 编排模式各有什么优势？
- ReAct Agent 的核心执行流程是什么？Thought、Action、Observation 分别承担什么作用？
- Agent 调用工具后，工具返回结果时消息结构如何设计？为什么需要单独设计 Tool Message？
- RAG 为什么需要父子索引？BM25 和向量检索怎么结合？Rerank 放在哪个阶段？
- 知识库持续更新时，如何处理向量索引更新、缓存失效以及旧文档仍被召回？
- Agent 训练中的 SFT、强化学习和 Agentic CFT 分别解决什么问题？为什么需要 Mask Observation Token？
- Redis 在 Agent 系统中承担哪些作用？消息队列为什么不直接用数据库替代？
- MySQL 联合索引何时失效？LIKE 什么时候能用索引？
- 如何反转单链表？

### 6-7 家中小公司 · Agent 面试复盘

技术深度最高的一份，**LangGraph 被问到实现层**：

- LangGraph 的节点如何传输数据？靠共享 State 是怎么做到的？
- 并行边 + 多节点操作一个 state 的结果会汇总到一个节点，state 如何汇总？
- langgraph 如何自定义中间件？中间件如何绑定到 langgraph？
- langgraph 如何挂载 tools，底层如何实现？
- MCP 三连问：实现方式有哪些 / streamable 格式是什么 / 如何与大模型结合并调用
- 一个文档做向量化和一个文档的一个块做向量化，结果维度是否一样？

## 面试官视角：为什么大多数人撑不过三轮追问

来源：一位面试官复盘"一上午面试了六个 Agent 开发岗"（♥760）。

**核心观察**：简历清一色写得很满（LangGraph、CrewAI、MCP、RAG、记忆系统关键词全覆盖），但**问到落地细节，大部分撑不过三轮追问**。

追问是怎么展开的：

1. 从**工具调用稳定性**切入：模型调工具报错、参数不符合 schema、下游服务超时，代码层面怎么做异常处理？
   → 多数人停留在"try-except 捕获一下"
2. 继续追问：模型是直接调 API，还是先走记忆检索？工具返回结果做不做格式校验？
   → 到这一步，回答开始**缺乏逻辑链条**
3. 简历写"精通记忆系统"的：用户对话到第二十轮，Agent 丢失了最早的关键信息，**排查路径是什么**？
   → 答不出记忆分层、上下文压缩、关键信息优先召回，说明只是在调接口层面打转

**他给出的准备方法**——把项目按四个维度重新拆一遍：

| 维度 | 要能答出的问题 |
|------|--------------|
| **数据层** | 知识库怎么清洗、按什么策略切分？ |
| **工具层** | 失败重试策略是什么，超时怎么降级？ |
| **记忆层** | 多轮上下文怎么管理，关键信息怎么召回？ |
| **工程层** | Token 成本怎么控制，异常怎么收敛？ |

**一套完整的方案至少应覆盖**：日志重放机制、关键节点断言、Bad Case 闭环复盘。

## 求职体感（来自 9 月一线候选人）

**"Agent 不是一个岗位，是一类岗位"**（已入职者复盘，♥29）

- 各家要的东西天差地别：偏模型应用的、偏工程落地的、偏中台架构的。没搞清楚方向，准备的东西大概率跑偏
- **2026 年的 Agent 面试根本不关心你 API 调得多顺，全程拷问工程化能力**——"大厂要的不是会写 Agent 的人，是能控住 Agent 不失控的人"
- 拿 RAG demo 去面，被问"召回不准怎么监控、怎么评测"直接卡住
- 投递渠道别只盯大厂官网：**国聘网、中智招聘**上有不少国企和子公司的 Agent 岗，竞争小很多

**"别被 JD 吓住，先上桌再说"**（♥23）

- 这行最大的特点是**没有统一标准**，JD 上"精通 Agent 架构"大半是 HR 抄的
- 新手搞定三样算入门：**工具调用、智能循环、MCP 协议**
- 想卷赢，重点搞三个：**沙箱隔离、记忆管理、Token 成本优化**
- 求职别只搜"Agent"，顺手搜"**智能体**""**LLM 应用**"

**"不用学那么多，多投多面才是最快的"**（♥682）

> "大概学了一个月，从 6 月中到 7 月中，找实习感觉还是看运气的，多投多面才是最快的。"
