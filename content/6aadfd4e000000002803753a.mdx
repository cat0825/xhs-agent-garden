## 核心判断

别被那些 JD 吓住，Agent 岗真没你想的高不可攀。这行最大的特点就是——**没有统一标准**。

同样叫 Agent 开发，A 公司可能就是调调 API 写写提示词，B 公司要搭多智能体系统，C 公司干脆是招自动化开发换了个 title。JD 上写的"精通 Agent 架构""熟练多智能体开发"，大半都是 HR 抄的，他们自己都说不清要招啥样的人。很多公司内部都还在摸索，招你进去就是一起踩坑一起迭代。

面试也一样，不爱问空理论，专揪落地细节：**死循环怎么处理、上下文爆了怎么优化、工具调崩了怎么快速恢复**。背八股文，不好使。

## 入门三件套

新手不用啃论文，搞定这三样就算入门：

1. **工具调用**——AI 怎么选工具、怎么传参、调失败了怎么重试。这是所有 Agent 能力的底座。
2. **智能循环**——Agent 接任务 → 思考 → 动手 → 看结果 → 再优化，整套闭环。这是 Agent 比 RAG 和普通问答更"智能"的根本。
3. **MCP 协议**——2026 年工具接入的主流标准，地位类似当年的 REST API，现在是刚需。

能自己跑通一套完整的 Agent 流程（接任务 → 调工具 → 出结果），就算过关了。

## 工具链别贪多

- **LangGraph 和 OpenAI Agents SDK，二选一吃透就行**。面试官不考 API 背默，只问你能不能讲清楚设计逻辑和运行机制。
- **FastAPI 和 Docker 是基本功**，必须会。
- 想卷赢别人，重点搞这三个：**沙箱隔离、记忆管理、Token 成本优化**。大部分人都不会控成本，你懂，就赢了。

## 开源项目：先跑通，再故意玩坏

Manus、MetaGPT 这些高星项目，先跑通，然后故意搞破坏：

- 让它无限迭代，看看怎么死
- 塞脏数据，看怎么崩
- 丢超长任务，看上下文怎么爆

这几个场景全是面试高频题，**你自己玩出来的经验，比背一百道八股文都管用**。

## 投递提醒

求职别只搜"Agent"，顺手搜搜"**智能体**""**LLM 应用**"——很多公司挂的岗位名字不一样，活儿差不多，别漏了。
