## 正文

Agent 开发岗当前火热 面试官说不定还没你懂 但是要学的内容也不多 强烈建议所有人去 github 找开源项目学习（不要买课！不要报班）
	
Ai 时代 开发的立身之本更侧重于工程架构能力 思维能力 沟通能力 自我驱动性 以前那种闷头写代码的时代已经过去了
	
面试了几场 给我的感觉就是比 java 八股文难度低太多了 只要真的写过几个项目 很轻松就能答上来 太高深的原理问题只要不是大厂基本也没人问你 小厂面试官还不一定比你懂！
	
最主要是的是薪资待遇比传统后端开发高很多 毕竟我们打工人都是奔着待遇去的嘛～
	
还发现一个现象 agent 岗位 非常看重 github （可能是现在企业 agent 少？）这边我推荐工作经验一两年或者应届生朋友们 根据一些实际场景去做一个属于自己的 agent 再基于这个 agent 写自己的技术博客 面试时大大加分～

### 图 p01：面试题回忆清单（备忘录截图，2026-07-24），正文没有的干货

1. 自我介绍
2. 你的 agent 是怎么学的，通过哪些渠道
3. 有一个消息领域模块，需要同时接收多端消息，但需要你封装成 SDK 或者对外接口，你如何设计
4. 问答场景中，如何保证用户的消息可以匹配到 RAG 中的知识呢
5. 项目中有没有用到 skills，或者日常工作中有没有用到 skills
6. 你用的 skill，怎么保证你换了别的 agent 或者别的大模型，起到的效果还是一致的？
7. 如果你负责的问答 agent 开发好了，但是老板说效果不好，你会怎么去排查？
8. 你有没有自己的 agent 项目，介绍一下背景、项目架构
9. 我们要设计 agent 分别给学生、销售、老师使用，你会如何设计？RAG 如何使用
10. 销售要给学生定制诊断方案，你如何设计这个 agent 的功能
11. 你平时怎么用 codex 等工具开发一个需求？从接到需求到上线的全流程说一遍
12. 你简历上这个 agent 的 xx 功能，从请求到返回的全流程技术方案讲一遍
13. 讲一下沙箱机制和 Harness
