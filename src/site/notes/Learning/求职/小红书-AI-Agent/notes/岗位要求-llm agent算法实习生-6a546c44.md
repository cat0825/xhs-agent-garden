llm agent算法实习生
岗位目标
加入 Agent 前沿技术与工程团队，作为实习生参与大语言模型多智能体（LLM Multi-Agent）系统的设计、开发与实验。通过探索前沿技术、推动模型优化及 Agent 工程落地，助力团队在实际应用场景中释放 Agent 技术的巨大潜力。
岗位职责
1.Agent 系统开发：参与大语言模型多智能体（LLM Multi-Agent）系统的工程架构设计与代码开发，协助完成系统落地。
2.模型优化：协助开展模型微调及 Prompt 优化实验，探索提升模型推理能力与 Agent 规划（Planning）能力的有效路径，持续迭代 Agent 。
3.工具链与环境集成：负责 Agent 相关的工具链开发（Tool Use / API Calling），以及 Agent 与外部环境交互接口的工程化集成。
4.数据分析与策略迭代：对系统运行结果和实验数据进行清洗与分析，提炼核心结论与关键发现，为工程优化和数据策略提供支撑。
5.前沿技术应用：持续追踪 Agent 及相关领域的业界前沿技术动态，并在工程实践中尝试应用最新开源技术与框架。
任职要求
1.基础条件：
●计算机科学（CS）、人工智能（AI）、软件工程及相关专业本科或硕士在读学生。
●具备扎实的计算机基础与编程能力，熟练运用 Python 语言。
2.优先考虑条件：
●拥有 Agent 相关项目的实际开发经验，或严谨的模型/数据对比实验经验，能提供相关开源贡献或项目成果展示（如附带 GitHub 链接）。
●具备成功将前沿大模型技术、开源 Agent 项目复现并工程化落地的实践经验。
●对解决复杂工程问题充满热情，具备较强的自我驱动力和团队沟通能力。
