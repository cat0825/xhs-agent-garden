### 蔚来 AI agent 开发实习生 — 岗位职责（图 p02）

1. **AI Agent 策略设计与研发**：基于开源的 AI Agent 框架（如 openclaw、nanoclaw），负责 Agent 的核心逻辑设计与链路编排。针对外部数据抓取与内部业务数据检索，设计高效的意图识别与数据提取策略。
2. **大模型自动化内容生成**：针对微信公众号、微博、小红书等多平台的内容生态，研发并优化基于 LLM 的自动化运营策略，通过 Prompt Engineering 提升图文生成的质量、相关性与转化率。
3. **大模型应用落地与工程化**：参与各类 AI 产品与飞书办公生态的深度集成，协助完成阶段性 Demo 的算法效果验证与功能验收，确保模型在真实场景下的稳定性与准确性。
4. **前沿技术追踪与预研**：持续关注并追踪 LLM、Agentic Workflow、RAG 等领域的最新学术进展与开源社区动态，配合团队完成新技术在具体业务场景（如自动化数据收集、内容营销、销售管理）下的可行性验证。

### 任职要求（图 p01）

1. 计算机、人工智能、数据科学等相关专业本科及以上学历，在校生。
2. 具备扎实的算法基础（机器学习/NLP 优先），熟练掌握 Python，具备良好的代码习惯。
3. 熟悉当前主流大模型的 API 调用与微调机制，有丰富的 Prompt Tuning 经验。
4. 熟悉 LangGraph、LlamaIndex、AutoGen 等 Agent 框架，对 RAG 原理及优化（如向量检索、重排序等）有实践经验者优先。
5. 了解基本的爬虫技术（如 BeautifulSoup、Selenium）或自动化 RPA 工具，能独立完成数据清洗与语料构建。

### 加分项（图 p01）

1. 有实际的 AI Agent 落地的项目经验，或在 GitHub 上有相关的开源贡献。
2. 了解企业级 API 接口对接（如飞书开放平台 API、微信公众号后台开发等）。
3. 有过自媒体/社交平台（如小红书、微博）自动化运营脚本开发经验优先。
4. 有在 AI Native 企业或大模型初创公司的实习经历。
