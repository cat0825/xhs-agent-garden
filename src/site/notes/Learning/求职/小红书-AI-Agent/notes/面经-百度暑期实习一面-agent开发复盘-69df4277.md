### 百度智能云一面 - agent 开发（图 p01，32 题）

1. 请先做一个简单的自我介绍。
2. 你在讯飞项目里前期用了 Milvus，后期又用了 FAISS，这样切换的原因是什么？
3. 你们当时对向量检索和混合检索的对比，是怎么设计的？
4. 你能再介绍一下学习陪伴导师这个项目吗？
5. 在这个项目里，你觉得自己做得最好的一点是什么？
6. 你在这个项目里主要负责后端整体架构设计，这段经历里你学到了什么？
7. 你当时为什么会基于那样的思路去设计这个 Agent？
8. 你项目里提到的中断控制、跨日会话切分、任务连续交互，具体是怎么做的？
9. 如果在交互过程中调用模型超时了，或者出现异常，你们是怎么处理中断和异常的？
10. 滑动窗口、摘要压缩、历史召回，这三种机制分别是在解决什么问题？
11. 你们是怎么做历史对话召回的？
12. 你们整个会话内容目前是存在哪里的？
13. 是磁盘存储还是数据库存储？
14. 你简历里写到基于 FastMCP 和 AgentScope 完成了工具封装，这部分具体是怎么抽象的？
15. 你在 Markdown 转 PDF 的过程中，为什么一开始用前端页面转换方案，后来又换成了 Pandoc + LaTeX？
16. 你们原来的转换链路具体是怎样的？
17. 在转换过程中，前期主要遇到过哪些渲染问题？比如字体、公式、表格这些问题具体是什么？
18. 你们最后是怎么验证转换成功率的？
19. 如果让你做一个真正上线的 RAG 系统，你最担心的 3 个问题是什么？
20. 你提到风控，具体指的是什么？
21. 如果要真正做输入和输出风控，你会有什么实现思路？
22. 如果用户一次性输入很多内容，比如上传 PDF 或文档，这种大输入场景下的风控怎么处理？是所有内容都全量检查吗？
23. 你平时有用过一些 skills 吗？
24. 你理解 skill 这种能力真正解决的是什么问题？
25. skill 和 MCP 这两种东西的区别是什么？
26. 你平时最常用的 AI coding 工具有哪些？掌握程度怎么样？
27. 你在用 AI coding 工具写项目的时候，是怎么防止它乱写、漏实现或者引入 bug 的？
28. 最近比较火的 OpenClaw 和 Harness Agent，你有了解过吗？
29. 你对 AI coding 大规模进入开发流程这件事，有没有自己的技术发展规划？会不会有焦虑？
30. 你对通用 Agent 的发展怎么看？
31. 如果把很多常用问题都以 skill 的形式输入给通用 Agent，它是不是就能解决所有问题？
32. 未来还需不需要继续做行业内、私域化、垂直领域的 Agent？你对这个问题有什么思考？
