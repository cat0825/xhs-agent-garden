## 跨帖共识（速览）

### 面试高频
1. 项目是否真做：State/Checkpoint、失败重试、SSE 流式、MCP 封装
2. Agent 边界：vs workflow / chatbot / RPA
3. RAG 工程：hybrid、OCR、rerank、评估（Ragas 等）
4. 工具层：Tool registry、MCP、Skill、Harness
5. 多 Agent：路由、并行状态、HITL
6. 后端底子：Redis/MySQL/锁/异步/FastAPI
7. 中等手撕几乎标配

### 用户反复点名的学习材料
- Datawhale **Agent-Learning-Hub**（Stage 0–8）
- **all-in-rag**
- hello-agent / hello-agents
- learn-claude-code + Anthropic/OpenAI 官方文
- 后端：FastAPI + 异步 + Redis + 任务队列
